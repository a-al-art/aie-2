# Конфигурационные файлы

В этой папке хранятся **настройки проекта**:

### `config.yaml` - Основной файл конфигурации. Содержит все параметры проекта:

- **data** - пути к файлам данных, размер тестовой выборки, случайное зерно
- **features** - списки числовых и категориальных признаков
- **training** - параметры обучения (количество фолдов CV)
- **models** - гиперпараметры Logistic Regression и CatBoost
- **artifacts** - пути для сохранения модели, препроцессора и метрик
- **service** - хост, порт и уровень логирования сервиса


### `.env.example` - Шаблон файла переменных окружения. В  проекте никаких секретов не используется - нет внешних API, токенов или паролей
