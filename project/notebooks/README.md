# Ноутбуки проекта

В эту папку помещаются **экспериментальные ноутбуки**:

Экспериментальные ноутбуки с анализом данных, построением признаков и сравнением моделей.

Весь «боевой» код (препроцессинг, обучение, инференс) вынесен в модульную структуру `src/`.

---

## Список ноутбуков

### `exp01_eda_baseline.ipynb` - Разведочный анализ данных (EDA)

Исследование исходного датасета: распределения признаков, дисбаланс классов, пропуски, выбросы, корреляции. Визуализации сохраняются в `artifacts/`.

**Основные выводы:** ярко выраженный дисбаланс классов, выбросы в возрасте и стаже, пропуски в ставке и стаже, сильные предикторы - `loan_grade`, `loan_int_rate`, `loan_percent_income`.

---

### `exp02_model_comparison.ipynb` - Сравнение моделей

Полный пайплайн обучения и сравнения двух моделей. Читает обработанные данные из `data/processed_dataset.csv`. Весь код обучения - внутри ноутбука.

Включает: разбивку данных, препроцессинг, SMOTE, обучение Logistic Regression и CatBoost, сравнение по метрикам (ROC-AUC, F1, Precision, Recall), ROC-кривые, матрицы ошибок, feature importance.

**Основные выводы:** CatBoost (ROC-AUC 0.9529) существенно превосходит Logistic Regression (ROC-AUC 0.88). Ключевые признаки по важности: `loan_grade_numeric`, `grade_rate_risk`, `loan_int_rate`. Высокий Recall критически важен: пропущенный дефолт дороже ложной тревоги - CatBoost при том же Recall имеет значительно более высокую Precision.

---

### `exp03_preprocessing_features.ipynb` - Препроцессинг и Feature Engineering

Исследовательский ноутбук: очистка данных, создание новых признаков, визуализация их распределений и корреляции с целевой переменной. Финальная логика реализована в `src/features/preprocessing.py`.

**Основные выводы:** наиболее информативные новые признаки - `grade_rate_risk`, `had_default`, `loan_grade_numeric`, `debt_to_monthly_income`.
